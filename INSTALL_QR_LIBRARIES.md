# Instalasi Library QR Code

Untuk menggunakan fitur QR Code kehadiran, Anda perlu menginstall library berikut:

```bash
npm install html5-qrcode qrcode.react
```

Atau jika menggunakan yarn:

```bash
yarn add html5-qrcode qrcode.react
```

## Library yang digunakan:

1. **html5-qrcode** - Untuk scanner QR Code menggunakan kamera
2. **qrcode.react** - Untuk generate dan menampilkan QR Code

Setelah install, restart development server:

```bash
npm run dev
```
